# C Language Practice Projects 🧠

This repository contains a collection of **academic and practical exercises written in the C programming language**, developed to strengthen foundational knowledge in **structured programming, algorithms, and low-level concepts**.

The content reflects hands-on practice carried out during coursework and independent study, focusing on problem solving, logical reasoning, and correct use of core C constructs.

---

## 📌 Repository Purpose

The main goals of this repository are to:

* Reinforce **procedural programming fundamentals in C**
* Practice **algorithm design and logical reasoning**
* Develop familiarity with **memory concepts, arrays, matrices, and pointers**
* Maintain a structured record of academic progress
* Serve as a technical reference for previously solved problems

This repository represents continuous learning rather than production-ready software.

---

## 🧠 Topics Covered

The exercises in this repository cover core concepts commonly taught in introductory and intermediate C programming courses, including:

* Input and output operations (`scanf`, `printf`)
* Conditional structures (`if`, `else`, `switch`)
* Loop constructs (`for`, `while`, `do-while`)
* Arrays and matrices
* Functions and modular code
* Basic pointer usage
* Problem solving using structured logic

Some folders and files correspond to **specific exercise lists, assignments, or instructors**, reflecting academic organization and progression.

## 🚀 How to Run the Programs

To compile and run any of the C files locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/FGaleti/Projetos-ATV-Linguagem-C.git
   cd Projetos-ATV-Linguagem-C
   ```

2. Compile a program using a C compiler (e.g., GCC):

   ```bash
   gcc program.c -o program
   ```

3. Execute the compiled file:

   ```bash
   ./program
   ```

> These programs are designed to run in a standard C environment (Linux, macOS, or Windows with GCC/MinGW).
